# Employee Management System

A learning-based full-stack project built to learn and practice modern web application development using Spring Boot, React.js, MySQL, and related technologies.

## 🎯 Aim

To strengthen full-stack development skills by building a real-world Employee Management System and applying concepts learned throughout the development process.

## 🛠️ Technologies

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Spring Security
- Maven

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Database
- MySQL

### Tools
- Git & GitHub
- IntelliJ IDEA
- Postman

## ✨ Planned Features

- Employee management
- Employee profile management
- Leave management
- Duty management
- Admin and employee roles
- Authentication and authorization
- REST APIs
- Input validation
- Exception handling
- React-based frontend

## 🚧 Project Status

Currently under development. Features are being implemented progressively as part of the learning process.
